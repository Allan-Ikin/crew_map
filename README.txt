WASTE ROUND MAP PROTOTYPE

Open index.html in a web browser. For full map and street lookup functionality, host the folder on GitHub Pages or another simple web host.

Included:
- Fortnight 1 / Thursday
- D1-D5 and R1-R5 imported from the supplied KMZ
- Searchable ordered street lists
- On-demand OpenStreetMap lookup and local caching
- Existing KMZ coordinates used where present
- Installable PWA shell

Important: the supplied KMZ mostly stores street names, not road geometry. This prototype therefore locates streets on demand. A production editor would save reviewed road lines as GeoJSON.
